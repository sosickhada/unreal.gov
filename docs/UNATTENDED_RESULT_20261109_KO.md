# 무인 점검 및 Gemini 단발 테스트 결과 (2026-11-09 UTC)

사용자의 무인 작업 지침에 따라 실제 Gemini 이미지 생성 요청을 최대 1회로 제한했다. 500원 초과 또는 모델·가격 미검증 시 차단하고, 실패 후 유료 재시도는 하지 않았다.

## 실제 API 결과

- Google 공식 [모델 문서](https://ai.google.dev/gemini-api/docs/models/gemini-nano-banana-2.1)와 [Standard 가격표](https://ai.google.dev/gemini-api/docs/pricing#gemini-nano-banana-2.1)를 HTTPS 200으로 재확인했다. 문서 응답은 `text/markdown`이었다.
- 모델 `gemini-nano-banana-2.1`, 2K 이미지 $0.0504, 입력 $1.50/백만 토큰, 텍스트·thinking 출력 $7.50/백만 토큰, 이미지 출력 $30/백만 토큰이 저장된 가격표와 일치했다.
- 입력 바이트·출력 토큰 상한, 설정 환율 1,800원/USD, 여유율 1.25를 적용한 보수적 1회 예약액은 **404원**이었다. 실시간 환율이나 실제 청구액이 아니다.
- 운영 DB의 기획 승인 완료 건 ID 6 / revision 1 / content 슬롯으로 별도 단발 프로세스에서 요청했다. 자동 생성의 영구 설정은 변경하지 않았고, 프로세스에만 생성 허용 및 재시도 0회를 적용했다.
- **07:37:30–07:37:32 UTC에 HTTP 요청 정확히 1회, HTTP 429로 실패. 재시도 0회.** 공급자 응답 본문은 기록하지 않아 쿼터·결제·속도 제한 중 정확한 원인은 확인하지 않았다. 추가 유료 요청은 수행하지 않는다.
- 운영 원장에는 attempt 0 / `failed` / `http_429` / 예약 404원이 남았다. usageMetadata가 없으므로 실제 청구액은 확인되지 않았다. 예약액을 실제 사용액으로 보고하거나 자동 환급하지 않았다.
- 이미지 생성이 실패하여 **Telegram 이미지 전송은 수행하지 못했다**. 합성 fixture를 실제 생성 결과로 대신 전송하지 않았다.
- 단발 스크립트는 첫 전송 전에 배타적으로 요청 시작 파일을 생성해 같은 실행물의 재호출을 차단했다. 산출물은 Git 제외 경로 `output/gemini-live-pilot-20261109/`에 보관했다.
