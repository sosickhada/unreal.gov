# 첫 공식 콘텐츠: 무료 배송의 추가 지출 사건

원고: `content/first-official-shipping.json`.
운영 레코드: 7번 v2. 테스트 게시물 4번과 별도 버전/자산/승인으로 관리한다.

테스트 게시물 4번은 2026-11-10 사용자 지시에 따라 철회했다. 당시 공개 게시 ID와
사용자 취소 이벤트는 없었다. 승인은 0으로 해제하고 대기 게시 작업은 `cancelled`로
변경했으며 Telegram 메시지 132의 키보드를 제거했다. 기존 버튼 재전송/클릭으로
철회한 게시물이 승인되지 않는다.

새 원고는 비용 계산(4,800원 추가 구매 - 3,000원 배송비 절감 = 1,800원 지출 증가)을
짧은 행정 풍자로 구성했다. 본문에는 중복 면책 문구를 넣지 않고 캡션에 짧은 풍자 창작
고지와 관련 해시태그 6개를 넣었다. 원고는 실제 newline을 사용한다.

Telegram 원고 기획 승인: `planning_approved`, revision 2,
2026-11-10T01:43:11.103743+00:00. 이 승인은 공개 게시 승인이 아니다.
AI 또는 운영자가 사용자 기획 승인을 생성하지 않았다.

선정 사진(원본 다운로드 후 얼굴·로고·주제 관련성·해상도를 편집 검토):
- 본문 세제: https://www.pexels.com/photo/plastic-bottle-of-detergent-in-studio-5218021/
- 표지/심의 택배: https://www.pexels.com/photo/brown-cardboard-box-beside-white-wooden-door-6170455/
- 라이선스: https://www.pexels.com/license/

출처와 라이선스 URL, 원본 해시, `codex-editor-visual-inspection` 편집 검토자 및
최종 사용자 검토 필요 표시를 `image_inputs`와 자산 provenance에 보존한다.
사용자 업로드/선택 경로는 기존 OWN 선언·버전 결합·슬롯 검증을 유지한다.
이번 콘텐츠는 사용자가 업로드한 사진이라고 기록하지 않는다.

실제 카드뉴스는 표지 → 사건 경위 → 심의 경과 → 최종 판정 → 고정 엔딩의 5장이다.
표지에 기본 Slack 이미지를 사용하지 않는다. 새 사건번호는 2026-1110-001이다.
공식 콘텐츠 본문은 원본 40px로 렌더링하여 390px 피드에서 약 14.4px 크기를 유지한다.
텍스트는 양쪽 80px 여백 안에 두고, Chromium 폰트 로드·텍스트 넘침·이미지 디코드를
검사한다. 최종 JPEG는 RGB 1080×1350이며 공개 바이트를 원본 해시와 대조한다.

`publication_kind=official`과 완성 원고/캡션, 주제 사진 2개 provenance, 최종 이미지 5개를
실제 Instagram 게시 경계에서 검사한다. 테스트/임시/placeholder 문구와 잘못 이스케이프된
newline, 해시태그 누락, 검토 전 이미지 및 기본 표지 사용을 차단한다.

원고 승인 후 Worker가 실제 렌더링하고, 앨범 전송 성공에 의존하는 별도 Instagram
공개 게시 승인 UI를 만든다. 사용자가 해당 계정·원고·이미지 fingerprint에 대해
승인해야만 공개 게시 작업을 생성한다. 게시 성공 시 기존 durable checkpoint와
게시 ID/URL 저장 및 Telegram 알림 경로를 유지한다. 게시 API 결과가 불명확하면
자동 재시도하지 않는다.

공식 렌더링은 기존 180초 한도로 편집 시안의 5장을 완성하지 못해, 운영 렌더링 상한을
300초로 조정했다. 서비스 종료 유예도 330초로 맞춰 정상 작업의 중간 강제 종료를 피한다.
모든 대기는 여전히 유한하며 완료 manifest 없이는 실패한다.

실제 렌더링 QA: 5장 저장 완료, 모든 폰트 로드 성공, 텍스트 넘침 및 깨진 이미지 0건.
주요 텍스트 하단은 최대 1,066px로 중앙 정사각형 크롭 하단 1,215px 안에 위치한다.
원본 5장도 직접 시각 검토했다. 비공개 QA 기록은
`data/official-shipping/layout-audit.json`, 상세 trace는
`data/render-traces/7-v2-trace.json`에 보존한다. 정상 렌더링은 226.492초에 종료됐다.

브라우저 시작은 90초, 각 캡처는 60초 이내로 제한했다. 테스트와 렌더링을 동시에
실행했을 때 캡처의 기존 15초 제한에 걸리는 문제를 실제 운영에서 확인했다.
공개 게시/유료 API를 재시도하지 않고 실패한 로컬 렌더링 단계만 재개했다.

최종 Telegram 전송 성공: 앨범 메시지 138–142, 계정·실제 캡션·승인/취소 UI 메시지 143.
전송 시점에는 최종 승인이 0이며 공개 게시 작업이 없었다. 최종 승인은 이 메시지의
정확한 원고·사진·계정 fingerprint에만 유효하다.

검증 결과: 전체 Python unittest 182개 통과, 최신 공식 콘텐츠 검사/승인 의존성
통합 테스트 5개 통과, Node 테스트 4개 통과. 공개 HTTPS 응답과 로컬 JPEG 해시 검증도
실제 Worker에서 통과했다. 이 시점의 다음 단계는 사용자의 별도 공개 게시 승인이다.
