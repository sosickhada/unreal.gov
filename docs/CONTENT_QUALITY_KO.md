# 콘텐츠 품질 운영 변경

운영 DB는 SQLite backup API로 `backups/quality-20261109T054709Z.db`에 백업했다. 모든 스키마 변경은 추가 방식이다. 후보·승인·거절·게시 이력은 삭제하지 않는다.

## 후보와 피드백

- 모델 모드: 일상 후보 최소 9개, 관련 뉴스가 있으면 별도 호출로 뉴스 후보를 생성한다. 뉴스는 사실 검증으로 취급하지 않는다.
- 내부 평가/탈락은 `idea_audits`, 기존 및 신규 사건 분해는 `idea_structures`에 저장한다.
- 공감25 / 구체성20 / 기관 패러디20 / 유머20 / 참신성15. 모델의 evaluation 및 로컬 구조 근거를 기록한다. 70점 미만은 제외한다. 점수는 재미의 검증 결과가 아니다.
- 최근 거절 사유와 과거 사건을 생성 프롬프트에 제공한다. 기준 미달·중복 시 별도 체크포인트로 최대 한 번 새 사건 생성을 요청한다. 호출 예산·불확실 요청 보호는 유지한다.
- 로컬 모드는 장소와 이해관계 사건을 조합한 제한적인 대안이다. 무한한 창의성을 보장하지 않으며, 중복 제거 후 3개를 확보하지 못하면 대기한다. 운영은 모델 모드를 사용한다.
- 30일: 같은 핵심 갈등 제외. 90일: 상황 및 갈등·원인·판정 구조를 비교하고 새로운 관점 없는 유사 사건 제외. 게시 이력은 기간 제한 없이 더 낮은 구조 유사도 임계값을 사용한다.
- 로컬 한글 3-gram, 문자열 비교, 동의 개념군 기반 유사도를 병행한다. 신경망 임베딩은 아니며 한국어 의역을 완벽하게 탐지하지 못한다. Claude 경계 사례 추가 판정은 아직 구현하지 않았다.
- 같은 날 후보 간에도 동일 검사를 적용한다. 거절된 후보를 이력에서 빼지 않는다.
- `재미없음` → 4개 표준 사유 또는 기타 직접 입력. `candidate_feedback`의 후보 ID 기본키와 교체 작업 고유키로 중복 클릭/재시작을 방어한다. 기타 입력 대기는 DB에 저장한다.
- 교체 시 원래 후보를 거절 상태로 보존하며 같은 위치에 새 ID를 만든다. 나머지 두 후보는 보존하고 새 후보만 전송한다. 전체 후보 재생성은 유지한다.

## 사진과 생성 이미지

Pixabay 검색, 원본 해상도·구도/관련성·시각 품질 검사와 Telegram 사진 선택 흐름을 유지한다. 라이선스 정책 근거와 실제 제3자 권리 보장은 구분한다.

무료 API 조사:

- Hugging Face 공식 요금 문서: 무료 크레딧 이후 요청은 과금 구조이며, 모델별 상업 이용 조건도 별도 확인해야 한다. https://huggingface.co/docs/inference-providers/pricing
- Cloudflare 공식 요금 문서: Workers Free에 10,000 Neurons/일, 초과 시 실패. Paid에서는 초과 과금이 가능하다. 계정 플랜과 이미지 모델 라이선스를 검증하지 않은 상태로 자동 연결하지 않았다. https://developers.cloudflare.com/workers-ai/platform/pricing/
- 무료 클라우드 API를 검증 완료 또는 실제 연동 완료로 보고하지 않는다. 이미지 API 키나 결제 설정은 새로 저장하지 않았다.

대안으로 `bureau/generated_images.py`에 로컬 Diffusers 생성 경로를 추가했다. 모델 다운로드나 유료 API 호출은 하지 않는다. 로컬 파일만 읽고 자연광·다큐멘터리·4:5 구도, 문구/로고/HDR/비정상 피부·손·얼굴 제외 프롬프트를 사용한다. 생성 결과는 해상도·선명도 검사 후 Telegram 미리보기 및 `/photos ID` 선택 대상으로 제공된다. 자동 승인하지 않고 주제·해부학·모델 라이선스의 사람 검토가 필요하다. 본문/결의에 동일 바이트 이미지는 사용할 수 없다.

추가 설정(선택): 로컬 Diffusers/torch 설치 및 충분한 메모리, 상업 이용 가능한 모델 파일. 환경변수 `LOCAL_IMAGE_MODEL_DIR`, `LOCAL_IMAGE_MODEL_SOURCE_URL`, `LOCAL_IMAGE_MODEL_LICENSE_URL`, `LOCAL_IMAGE_MODEL_LICENSE`. 라이선스 URL이 있다는 이유만으로 검증 완료 처리하지 않는다. 실제 로컬 생성 실행은 모델 미설치로 검증하지 않았다.

## 허구 고지

서사 카드 템플릿의 우측 하단(오른쪽65px, 하단34px)에 `※ 본 사건은 허구입니다.`를 19px로 배치한다. 본문/판정 상단 사건번호(21px)와 같은 ROKG 서체 계열이다. 본문 경계 검사는 하단1270px로 강화해 고지 영역을 확보했다. 이전 고지 문장을 본문에서 제거하고 판정 템플릿 중첩 시에도 한 번만 표시한다. 프롬프트도 본문 고지 대신 caption의 풍자·창작 설명을 요구한다. 고정 엔딩 원본 이미지는 그대로 보존한다. 실존 인물 혼동 위험은 caption에 추가 설명하도록 지시한다.

## 운영 적용 및 검증 (2026-11-09 UTC)

- 관리자 권한으로 Telegram/Worker를 정지한 뒤 추가 DB 백업·마이그레이션을 수행하고 서비스를 재시작했다. 선택/승인 관련 `selections`는 7 → 7건, 과거 후보 분해는 30건이다. `PRAGMA quick_check=ok`를 확인했다.
- 운영 환경은 `CANDIDATE_GENERATION_MODE=model`, `USE_NEWS_REFERENCE=1`로 변경했다. 비밀값은 출력하거나 커밋하지 않았다.
- Telegram, Worker는 active/running, 후보 timer는 active/waiting이다. 두 번째 polling 프로세스를 실행하지 않았다.
- 전송 확인 메시지 한 건의 outbox 상태가 sent이며 error_code는 없다. 실제 사용자 버튼 클릭은 자동 조작하지 않았다. 버튼·직접 입력·재시작 후 대기는 모의 Telegram 테스트로 검증했다.
- 전체 unittest 127개를 실행했다. 126개 통과, 설정 누락 시 고정 후보를 보내던 이전 기대값 1개가 실패했다. 해당 기대값을 검토 대기·후보 0건으로 수정한 후 preflight/새 편집 검사/피드백 관련 18개를 다시 실행해 모두 통과했다. 이를 수정 후 전체 127개를 한 번에 재실행해 모두 통과한 결과로 표현하지 않는다.
- 초기 실제 렌더는 페이지 로딩/글꼴·레이아웃 검사 제한을 넘었다. 변경 전 렌더러와 비교하고 navigation 45초, 레이아웃 평가 30초로 조정한 후 Chromium 5장 렌더 smoke가 111.58초에 통과했다. 글꼴·이미지 로딩 및 넘침 검사 통과, 고정 엔딩 픽셀 보존을 확인했다. 표지/본문 PNG를 열어 우측 하단 고지 위치와 가독성을 확인했다. 결과: `output/quality-render-verified/case-5-report.json`.
- 로컬 생성 모델이 없어 실제 AI 생성·품질 검증을 실행하지 않았다. 무료 클라우드 이미지 API, 유료 이미지 API 및 Instagram 공개 게시는 호출하지 않았다.
- 코드 커밋 `a00af4a`를 GitHub `feat/full-automation-cloud` 브랜치로 푸시했다.
- 최종 전체 오프라인 파이프라인도 PASS: `output/offline-acceptance/2026-11-09T06-26-14.295341+00-00/report.json`. 외부 호출 0, Claude 모의 호출 3회(일상/뉴스/기획), Telegram 모의 전송 4회, 실제 Chromium 5장 렌더, 서로 다른 본문/결의 사진, 원본 페이지 1/4/5 픽셀 보존, 승인 후 `publish_waiting` 및 Instagram 실제 게시 0을 확인했다. 합성 사진 fixture의 통과를 실제 사진 품질·라이선스 검증으로 취급하지 않는다.
